# Approved painted trunk joins

These are exact copies of the 24 approved localized edits, not regenerated alternatives. `provenance.json` pins the source repository/commit, patch hashes and original stage-painting hashes. Source references, generator outputs, masks and exact prompts remain in the linked preview repository.

The PNGs are frozen masked donors. They include the study's brown background inside their alpha ellipse. `ui/painted-root-joins.js` removes that known matte once per decoded image and caches the transparent result; it does not alter these files. The game preserves the source trunk above its measured collar and overlays the approved patch on the five-axis network. Extra original root strips are deliberately not drawn, because they would show as detached remnants after matte removal.

`ui/root-join-profiles.js` records every species/stage's source collar and dimensions. Root IDs/curves persist in normalized collar coordinates; stage changes rescale them with the trunk and update bark. This is not a promise of fixed world coordinates or identical juvenile painted roots across the first woody handoff.

Detailed procedural root layers use a global eight-entry LRU, each capped at a 1536 px long edge. Camera measurement reuses the same cached layer instead of repainting every bark strip repeatedly. Cache recovery discards these derived canvases and the matte, not the approved decoded images or gameplay state.
