# Painted event specimens

`moonlit-night-branches-v3.png` is the current transparent upper-right specimen for the Night Falls field-journal sheet: its moon sits left of center inside an irregular indigo watercolor bloom, with sparse branches concentrated along the right edge for an asymmetric, non-eye-like silhouette at phone scale. `moonlit-night-branches-v1.png`, `moonlit-night-branches-v2.png`, and `moonlit-grove-v1.png` are superseded specimens retained for provenance. `fungal-blight-v1.png`, `damp-rot-v1.png`, and `airborne-spores-v1.png` are independently usable transparent encounter portraits extracted from a deliberately spaced three-subject source sheet. `forest-gift-v1.png` is a compact rabbit-dropping specimen, and `mycorrhizal-bloom-v1.png` is a distinct feeder-root and beneficial-mycelium specimen; neither reuses a tree life-stage painting.

The full-size generated masters are preserved outside the repository in `~/.openclaw/playground/trees-night-events/masters/`. `prompts.json` records the built-in image-generation prompts and SHA-256 hashes for both masters and all runtime derivatives. Runtime images were downscaled with Lanczos filtering and retain alpha.
