# Painted event specimens

`moonlit-night-branches-v1.png` is the current transparent upper-right specimen for the Night Falls field-journal sheet: one large moon, a simple indigo sky, and sparse dark branches chosen for phone-scale legibility. `moonlit-grove-v1.png` is the superseded detailed grove specimen retained for provenance. `fungal-blight-v1.png`, `damp-rot-v1.png`, and `airborne-spores-v1.png` are independently usable transparent encounter portraits extracted from a deliberately spaced three-subject source sheet.

The full-size generated masters are preserved outside the repository in `~/.openclaw/playground/trees-night-events/masters/`. `prompts.json` records the built-in image-generation prompts and SHA-256 hashes for both masters and all runtime derivatives. Runtime images were downscaled with Lanczos filtering and retain alpha.
