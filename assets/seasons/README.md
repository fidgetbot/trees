# Season card artwork

The four runtime PNGs are transparent botanical specimens used by the blocking card shown whenever the season changes.

- `spring-card-art-v1.png`
- `summer-card-art-v1.png`
- `autumn-card-art-v1.png`
- `winter-card-art-v1.png`

`source/four-season-card-art-master-v1.png` is the approved 2×2 generated source sheet. The runtime files are lossless quadrant crops from that exact master; no repainting or color adjustment was applied after approval.

Generation details and hashes are recorded in `prompts.json`.
